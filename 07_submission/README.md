# 07_submission — 最终提交物

> 队长负责。**三份文件在竞赛系统里分别上传**，不是打成一个 zip。

| 文件 | 命名 | 内容 | 大小上限 |
|---|---|---|---|
| 论文 | `BSWBMCM2613050.pdf` | 最终论文 | < 20 MB |
| 承诺书 | `BSWBMCM2613050cns.pdf` / `.jpg` / `.png` | 三人手写或电子签名后扫描 | < 20 MB |
| 支撑材料 | `BSWBMCM2613050fj.zip` / `.rar` | 全部源码、数据、程序 | < 20 MB |

（`B` = 题号字母；`SWBMCM2613050` = 队号）

## 上传流程要点

1. 上传后**必须点「点击提交」**，左上角显示「已提交」才算交上。**只上传不点是没交。**
2. 改稿要先**删除已上传的旧文件**，再传新版。
3. 可反复提交，**只保留最后一次**。
4. 备用邮箱与官网提交**二者择一，不可重复**。

## 支撑材料里放什么

- 全部可运行源码（`03_code/`）
- 软件名 + 关键命令（写一个 `README.txt` 在压缩包根）
- 数据与结果 CSV
- 赛题已给的数据**不必**放进去
- **代码注释里不能有姓名/学校**（匿名评审）

## 不放什么

- ❌ 带签名的承诺书原件（含手写签名，只提交扫描后的 PDF，`.gitignore` 已排除）
- ❌ 含学号、手机号、邮箱、地址的任何文件
- ❌ 二维码图片（公众号二维码之类，PDF 里也不能有）

## 交完记得

- [ ] 左上角显示「已提交」
- [ ] 三份文件都上传成功、都能下载回来
- [ ] 论文 PDF 自己打开看一遍（页数、页眉、目录、字体）
- [ ] 提交时间早于 11-24 10:00（保守按 09:00 停改内容）
