# 仿真可行性与工具选型

**赛时推荐 Python 事件回放＋已有矢量出图，三维展示优先 Plotly。本题暂不采用 COMSOL 或 CARLA-Air。** 配图中最值得保留的是场地、车辆、无人机、射线和同步事件的同屏呈现。面向比赛的最小成品是对已验证结果可定位、可暂停、可比较的回放。

## 1. 三层仿真

| 层 | 可用输入与核验目标 | 推荐产物 |
|---|---|---|
| A 确定性几何 | 官方 100×100 m、五栋长方体、实际楼高、1.5 m 车体、2 m 相机、对应目标坐标、可见谓词。校核光线和地面运动分别用 3D 与 2D 几何 | P1 2D 主图与带高度刻度的 3D 小视图，选择站点后显示三个约束值 |
| B 动态事件 | `B_timelines.json` / `B_P4_cross_timelines.json`，路径和绝对事件时刻。记录提供的按里程插值、阶段和同步。完整缓存语义与仅进行中语义分别出日志 | 双政策同步时钟回放、开测完成数阶梯、逐车甘特。保留一个改善例和一个失败或持平例 |
| C 概率实验 | P3 已核验积分曲线、五点 MC/Wilson、输出方差比例。P4 是可追溯的配对情景，只有失败车等概率明确给定 | 覆盖曲线、参数区和贡献图，P4 分面情景表。场景概率仅在有明示概率模型时使用 |

## 2. COMSOL 七项判断

| 问题 | 判断 |
|---|---|
| 连续物理场 | 题设的连续量为坐标、线段、行车和转向时间。没有观测流场、建筑材料、射频传播或连续介质测量字段。 |
| 方程和边界 | 标称匀速、转轴最大角速度和几何限制给出运动学。COMSOL PDE 接口需要对应的未知场、方程、边界条件和参数。本题未提供满足该目的的物理输入。 |
| 与定位关联 | 可见性由有限段和棱柱接触决定；P2(1) 方位噪声与 P3 误差模型已给定。新增传播场无法与题设噪声、遮挡或行车指标校准。 |
| 科学价值 | 缺少独立实验数据与新增可判别假设。做流体、电磁、动力学或声学场都没有本题验证对象。 |
| 对比 Python | COMSOL 长项是经标定的连续场网格、求解和后处理，商业环境依赖高。Python 可直接消费已有 CSV/JSON、执行事件和统计复核，和题目输出一致。 |
| 预计工时 | 安装及授权状态未核实。软件与许可均就绪的假设下，试建/出图评估预留 4–8 人时，额外科学模型的验证工作因数据缺失无法定量。 |
| 赛时决策 | 使用 A/B/C 三层数据产品。COMSOL 适合赛后且有新物理数据的研究问题。 |

[COMSOL 的 PDE 接口和边界条件说明](https://www.comsol.com/support/learning-center/article/modeling-with-partial-differential-equations-in-comsol-multiphysics-45321)

## 3. 工具比较

工时按一位熟悉 Python 的队员、已验收 CSV/JSON、单机环境估计。三维与回放为工程范围估计，未实装压测。

| 工具 | 数学计算 | 3D、遮挡与动态 | 车辆/接口 | 开发与运行 | 交付判断 |
|---|---|---|---|---|---|
| Python＋现有 ReportLab | 现有求解器和验证可复跑；必要时评估 SciPy 积分 | 2D 矢量成熟；3D 可作为静态立体投影 | 事件与路点原生读取 CSV/JSON | 整理数据到图 1–3 人时，低开销；依赖 Poppler 和字体可固化 | 正式图表和验收首选 |
| PyVista/VTK | 渲染辅助，复用几何判定 | 棱柱、相机、线段、离屏截图/写帧 | NumPy/VTK 接口，自定义轨迹事件 | 3–7 人时；VTK、OpenGL 和视频编码可增加环境成本 | 适合高质量静态 3D 或离线视频，有现成可用环境才加 |
| Plotly | 数据展示与统计图 | 交互 3D、滑条、帧与双面板。建筑半透明仅是表达，遮挡事件读取已经计算的值 | CSV/JSON → Python 或 JS；轨迹和事件按数据更新 | MVP 2–4 人时；帧多和体积大会增加页面负担。当前 Python 未安装 Plotly | 最适合组内浏览回放。复现可固定依赖，论文插官方证据生成的静态帧 |
| Blender | 可脚本校核输入；通用渲染长项 | 材质、光照、摄像与视频；物理仿真默认参数需禁用或明确隔离 | Python 脚本按路径数据设关键帧 | 6–12 人时＋渲染/素材工时；当前命令不可见 | 作品展示可评估，赛内不作为主证据 |
| CARLA-Air / OpenHUTB | 一般不承担本题估计或排程的数学证书 | 真实街景与空地实体表现强，具备传感环境和仿真框架潜力 | 用项目 API 接场景和轨迹，版本、车辆类型、自定义地图需先核实 | 1–2 人日以上，GPU、引擎和环境成本较高。未核实本机可运行 | 构思图的展示参考；本题空地协同能用简洁棱柱场景验证，赛内暂缓 |
| COMSOL Multiphysics | 连续介质 PDE/FEA 能力强 | 连续场动画与三维网格，离散车辆状态需定制 | 模型文件/表格及脚本接口，还有授权约束 | 4–8 人时仅指基本试装/试建范围，验证缺数据 | 本题缺少进入求解器的物理问题 |

参考文档：[SciPy 积分](https://docs.scipy.org/doc/scipy/reference/integrate.html) · [PyVista 写帧](https://docs.pyvista.org/api/plotting/_autosummary/pyvista.plotter.open_movie) · [Plotly 帧](https://plotly.com/python/animations/) · [Blender 命令行渲染](https://docs.blender.org/manual/en/latest/advanced/command_line/render.html) · [OpenHUTB 项目](https://github.com/OpenHUTB/hutb)。

## 4. 构思图到 MVP

| 构思图位置 | 应保留的信息 | 实际输出 |
|---|---|---|
| 上半空地场景 | 东、北、高同尺度，车辆与无人机实体，地面路径和射线 | 五栋官方棱柱、一套贴齐平面图的顶视和斜视，标称三目标位置。夜景、人群、交通和多模态传感画面仅属构思素材 |
| 01 几何定位 | 视线与遮挡，最优可行区 | 叠加 P1 栅格层、圆角边、边界圆和最优分支；LOS 用二值与接触点编码 |
| 02 协同调度 | 路径、车序、复用 | 选定名义与基线，按相同时间轴追踪车辆及云台；复用路段零行驶仍保留阶段动画 |
| 03 误差传播 | 误差统计值与覆盖阈值 | 把 P3 概率曲线作为独立页签。若显示误差随机样本，标注“第几次抽样”和种子。保持固定 40 m 条件，禁止把插值轨迹伪装成带误差测量 |
| 04 故障恢复 | 事件、断联、失败退出、重新分配 | 保留和改派并排，故障时冻结故障车图标或标退出，页面显示计划版本、断联策略、时钟与真实 $(k/N,t_{last})$ |

### 回放契约

- 场景选择至少含标称方案、组合扰动收益、持平或 V5 单故障变差。投影几何复用官方场尺寸、楼高、相机位置。
- 钟表固定用绝对秒。事件表提供 depart、arrival、ready、start、end、reset；位置通过当期路段弧长和速度插值，阶段驻车保持坐标。
- 云台按实际求解的事件时间展示。若现有日志只给总耗时，帧内角度需注明采用指定轴速策略做可视化插值，保证起末角、两轴上限、正东行车和结束回零匹配。存在中途取消时，需有对应姿态状态才能精确回放。
- 优先翻查 P4 JSON 的 `nominal_before_replan`：它提供名义的派遣前缀，含失败或被取消的计划。真正发生与被取消的事件需独立标签或由队员确认后的事件导出生成，严禁原数组直读为真实所有动作。
- 验收测试：路径各断点坐标、到位停车、每告警两车同步、前后复位、故障车退出、恢复前无新命令、阈值边界、计分与结果表一致。在 5 s、恢复时刻和 60 s 前后单帧比对。
- 交付顺序：正式静态图 → 一组合案例可回放 → 对照面板。若正式数字或论文证据未封版，优先处理证据。建议回放开发设置 4 人时上限，由队员决定是否扩展。

## 5. 提交范围

- 论文只放英文、可复查的静态图或帧，不嵌程序、二维码或媒体。论文、承诺书与支撑压缩包使用官方命名分别提交。
- 官方允许支撑 ZIP/RAR 提供程序、必要数据和中间证据，且相关源程序须可运行。独立视频、引擎大工程及交互 HTML 没有单独的正式提交项。演示可供组内/答辩使用；允许的支撑材料内容以正式系统及队员核定为准。
- 关键论文图首选矢量 PDF。PNG 300 dpi 供预览；显示器观感与印刷可读性分别检查。软件效果示意图作为设计参考，不能作为实证图。[官方提交流程](https://www.nmmcm.org.cn/News/222.html)
