## 0. 输入、符号和题设口径

| 符号或字段 | 含义与单位 | 来源 |
|---|---|---|
| $X,Y$；$O$ | 东、北坐标 m；调度中心 (50,50) m | p.1 |
| $F_j,H_j$ | 建筑平面闭矩形和高度 m | p.1 Table 1，CSV 五行对象 |
| $p_i,p_i^0$ | 车辆圆心 xy、初始 xy，摄像机高 2 m | pp.1、3 |
| $r_v,v$ | 圆盘 1.5 m、行车 3 m/s | p.2 |
| $θ,R,H$ | 告警正东逆时针方位 °、相对中心水平距离 m、目标高 m | pp.1–2 |
| $r,α,β$ | **站到目标**水平距 m、相机方位 °、相机俯仰 °；另以 $φ$ 表示从目标看站位的极角 | pp.1–3 |
| $D(p,q)$；$B,γ$ | 路线距离 m；站间基线 m、交会角 ° | pp.2–4 |
| $t_d,t_a,t_q,t_s,t_e,t_u$ | 出发、到站、对准就绪、联合开测、结束、复位完成的绝对时刻 s | p.3 |

| $t_0,t_{rec},d_{out},t_h$ | P4 扰动 5 s、恢复绝对时刻、断联历时、窗口末端 60 s | p.5 |
| $k,N,η,t_{last}$ | 成功开测数、告警总数、完成率、官方计分的最晚开测时刻 | p.5 |

表内所有模型计算统一使用 m/s；明确角度函数输入是 ° 或 rad。官方仅 P3 指定误差；各问题先完成标称答案，再由队员批准扩展。阶段记录保留零时长动作，车辆导出 ID 统一显示 V1–V5，代码索引的 0–4 不可直接作为论文车号。五栋楼、初始点、三组告警及云台参数见 `../data/B题题面参数.csv`；转录主要数值已核对，未发现 B 题独立数据附件。

| 7 理论 | 旋转对称性、atan2、独立正态误差合成、周期区间、局部传播、条件积分与随机二项区间。 |

| 9 边界 | 位置方差近零、横向误差为零、估计位置跨目标、角度±180°、阈值附近、增大里程是否出现其他可行区、$a=0$ 或 $b=0$。 |
| 10 验证 | `solve_p3:181` 中积分域、节点数（64/128）和 bisection 精度审查。另测加密、缩放积分域、符号与包角边界；最大性需要单调性依据或覆盖全域证书。 |
| 11 实验 | 小误差区对比一阶；阈值前后验证覆盖曲线和 Wilson 区间；80 m 标称与参数域内/边/外夹具。三类贡献标成一阶方差比例，非线性单因子比较另命名。 |
| 12 图表 | 全域概率曲线＋95% 局部放大＋五点 CI；参数域和标称点；有真实证据时绘三项贡献趋势。 |

| 14 风险 | 误把云台两个标准差线性相加；将方位误差作水平位置误差；把阈值点跨越 95% 的 CI 当成独立达标认证；为 80 m 重复造加权假设。 |

## 待队员签核的证据接口

| 验证层 | 核验点 | 输出 |
|---|---|---|
| 符号与圆周 | 横向正 δy、估计刚跨目标、±180° 规则、偏移度数 | 逐项比较解析手算和程序角。对称噪声掩盖符号反向，要用固定输入夹具 |
| 极限与量纲 | 位置噪声趋 0、合成云台噪声、s=0 与 80 m | 命中概率范围在 [0,1]，输入 φ 和标准差单位一致 |
| 积分误差 | 64/128 当前节点，再选更密节点与更宽截断；核查周期累加选取 | 同一文件记录正态区间外质量、积分差、根求解停止条件及残差 |
| 阈值 | 临界点两边、自变量远离阈值、更大 s 边界 | 记录每侧概率、数值误差和允许报出的小数位数；证明或独立检查最大性 |
| 抽样 | 固定已报五点和额外边界夹具。保持分量独立，同模型独立实现 | 记录 seed、N、成功次数、Wilson 下上界；有多个工作点时注明区间是逐点 |
| 贡献 | 当前三类一阶比例，分量随 s 的权重 | 检查比例之和与 s 单位。若另跑去掉某类误差的消融，则明确比较指标并与局部方差占比区分 |
| 可调视场 | $a,b$ 两轴截距、一个边界点、标称点与内外两侧 | 报 a(m)、b(m/m) 和 80 m 的复核概率。勿把一次实景车程的全范围风险直接代入 |
