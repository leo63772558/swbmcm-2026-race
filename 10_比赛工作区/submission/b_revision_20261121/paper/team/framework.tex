Figure~\ref{fig:framework} shows how station feasibility, routing, dispatch, and event replay share the same field and vehicle parameters. The geometry layer provides the field inset, rounded building-clearance tests, elevation bounds, and three-dimensional ray--box occlusion checks. Problem 1 uses these tests to identify the best-quality arc and compare readiness and travel among its stations.

Problem 2(1) evaluates the bearing-intersection Jacobian and verifies an attainable analytical lower bound. Problem 2(2) searches discrete station candidates generated with the same geometry. An independent branch-and-bound search checks the latest paired start over the full discrete pool. The selected $k=8$ beam schedule has latest paired start $t_{\mathrm{last}}=\BBeamEight{}$~s and supplies the baseline for event replay and rescheduling. The result and replay scripts verify the digest of that plan before using it.

Problem 3 gives a distance limit $s_{\max}=\BIntegratedCrossing{}$~m under the given noise model and fixed 40~m target range. This threshold provides a reference for planning under that range assumption. Problem 4 uses a discrete-event simulator \cite{vantendeloo2018} initialized from the nominal schedule. It compares Keep Plan and Reschedule in 115 distinct disturbance cases, with 62 deduplicated cases from \BCaseCount{} archived IDs and 53 additional spatial stress cases. Every comparison prioritizes higher completion $\eta$ and then earlier latest start $t_{\mathrm{last}}$.
