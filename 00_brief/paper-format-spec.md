## 3. 论文文件的结构（数页数从这里算起）

```
第 1 页   Summary Sheet   ← Title + Summary + Keywords，必须同一页、必须是 PDF 首页
第 2 页   Content         ← 目录专用页，整页，不得塞正文
第 3 页起 Main Text       ← 正文，每页页眉 Team#… + Page N of M
…
第 ≤25 页 正文结束        ← 含摘要页、目录页在内，总数 ≤ 25
附录      Appendix        ← 页数不限；也可整体移到支撑材料，但正文要注明
```

**页数预算建议（25 页封顶）**：摘要 1 + 目录 1 + 正文 20~21 + 机动 2。附录不放正文里最省页。
> 规范「附录页数不限」与「附录可不写在论文之后」是同一条给的口子 —— **强烈建议把源码全放进 `...fj.zip`，正文只留一句注明**，把 25 页全留给得分内容。

## 4. Word 模板逐页解剖（实测，不是猜）

### 4.1 五个分节 / 页面设置

| 节 | 覆盖内容 | 纸张 | 上/下边距 | 左/右边距 | 页眉 | 特殊 |
|---|---|---|---|---|---|---|
| 0 | **第 1 页 摘要页** | **Letter 612×792pt**（21.59×27.94 cm） | 28.8 / 72 pt | 72 / 72 pt | **无页眉** | 只有首页页脚 |
| 1 | **第 2 页 目录页** | A4 595.3×841.9 pt | 72 / 72 pt | 90 / 90 pt | 有 | `different_first_page = true` |
| 2–4 | 正文各段 | A4 | 72 / 72 pt | 90 / 90 pt | 有 | 分节符保留，别合并 |

> ⚠️ 摘要页是 **Letter**，比 A4 宽 0.59 cm、短 1.76 cm（总面积反而更小）。这是官方模板自带的美赛版式，规范同时写「页面尺寸不大于 A4 幅面」。**建议照模板原样不动**（详见 §10 待确认项）；若自行统一成 A4，反而偏离官方样例。

### 4.2 字体与样式

- 文档默认：`Times New Roman`（西文）／`宋体`（东亚）→ 正文没中文，实际全是 TNR。
- 字号分布：`w:sz=24` → **12pt（57 处，正文主体）**；`36` → 18pt（标题）；`20` → 10pt；`40` → 20pt；另有 **3 处 Tahoma 残留**。
- 模板自述原文：*"This template uses a 12-point Times New Roman font… typed in English, with a readable font of at least 12-point type."*

### 4.3 模板自带的正文骨架（第 3 页起）

```
1. Introduction            1.1 Background / 1.2 Work
2. Problem analysis        2.1 Data analysis / 2.2 Analysis of question one
                           2.3 Analysis of question two / 2.4 / 2.5
3. Symbol and Assumptions  3.1 Symbol Description（5×3 空符号表）
                           3.2 Fundamental assumptions
4. Model
5. Test the Models
6. Sensitivity Analysis
7. Strengths and Weakness
8. Conclusion
References                 [1] [2] [3] [4] 占位
Appendix
```

- 目录页是**真正的 Word 自动 TOC 域**：`TOC \o "1-3" \h \z \u` + 22 组 `HYPERLINK`/`PAGEREF` 书签，**不是手打的文字**。
- 与我们 `07_英文论文工坊/guidelines/PAPER_STRUCTURE.md` 的差别：模板把「问题分析」「符号与假设」单列，且**多了 Validation 被合并进 5.Test the Models**。两套骨架可择优，但**目录页必须有**。

正文引用处：`... as shown in [3]`；**引用书籍还要写页码**，如 `[2, pp. 45–47]`。按**正文出现先后**编号，不是字母序。

```
书籍：[编号] 作者，书名，出版地: 出版社，出版年。
期刊：[编号] 作者，论文名，杂志名，卷期号: 起止页码，出版年。
网页：[编号] 作者，资源标题，网址，访问时间(年月日)。
```

> 官方原话「**参考文献尽量不要用网址，尽量使用论文期刊书籍之类的**」→ 优先 arXiv/期刊/教材，URL 只作补充。这也顺带压低相似比。
