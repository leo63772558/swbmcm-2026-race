## 三条最容易被忽略的

1. **页数 ≤ 25 页含摘要页和目录页**，附录不算 —— 很多人写到第 26 页才发现。
2. **表标题在上、图标题在下** —— 反了直接扣格式分。
3. **AI 使用必须申报**，不是"用了就用了"。见 `ai-usage-policy.md`。
