# 题面结构化数据（从 PDF 抄录）

> 生成脚本：`scripts/build_problem_data.py`（**不要手改 CSV**，要改就改脚本再重跑）
> 运行：`python scripts/build_problem_data.py`

## 文件与字段

### `buildings.csv` — 表 1 建筑平面范围与高度

| 字段 | 含义 | 单位 |
|---|---|---|
| `id` | 建筑编号 B1–B5 | — |
| `x_min_m` / `x_max_m` | 东西向范围 | m |
| `y_min_m` / `y_max_m` | 南北向范围 | m |
| `height_m` | 高度（柱体底面在 z=0） | m |

### `vehicles.csv` — 五辆待命车初始位置

| 字段 | 含义 | 单位 |
|---|---|---|
| `id` | V1–V5 | — |
| `x0_m` / `y0_m` | 初始位置坐标 | m |

### `alerts.csv` — 基准告警与其换算出的目标水平坐标

| 字段 | 含义 | 单位 |
|---|---|---|
| `id` | T1–T3 | — |
| `theta_deg` | 方位角，**自正东逆时针** | ° |
| `R_m` | 距调度中心的水平距离 | m |
| `H_m` | 目标高度（告警直接给出，不参与交会解算） | m |
| `x_target_m` / `y_target_m` | 由 `(50 + R·cosθ, 50 + R·sinθ)` 换算所得 | m |

### `params.csv` — 模型参数

场地尺寸、调度中心、车体半径与速度、相机高度、云台俯仰范围与角速度、联合观测时长、
P2 行程上限、方位角测量标准差、P4 评价窗口与扰动时刻。
