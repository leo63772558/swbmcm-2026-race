## 0. 输入、符号和题设口径

| 符号或字段 | 含义与单位 | 来源 |
|---|---|---|
| $X,Y$；$O$ | 东、北坐标 m；调度中心 (50,50) m | p.1 |
| $F_j,H_j$ | 建筑平面闭矩形和高度 m | p.1 Table 1，CSV 五行对象 |
| $p_i,p_i^0$ | 车辆圆心 xy、初始 xy，摄像机高 2 m | pp.1、3 |
| $r_v,v$ | 圆盘 1.5 m、行车 3 m/s | p.2 |
| $θ,R,H$ | 告警正东逆时针方位 °、相对中心水平距离 m、目标高 m | pp.1–2 |
| $r,α,β$ | **站到目标**水平距 m、相机方位 °、相机俯仰 °；另以 $φ$ 表示从目标看站位的极角 | pp.1–3 |
| $D(p,q)$；$B,γ$ | 路线距离 m；站间基线 m、交会角 ° | pp.2–4 |
| $t_d,t_a,t_q,t_s,t_e,t_u$ | 出发、到站、对准就绪、联合开测、结束、复位完成的绝对时刻 s | p.3 |
| $s,σ(s),Δψ$ | 累计里程 m、单轴定位标准差 m、包角误差 ° | pp.4–5 |
| $t_0,t_{rec},d_{out},t_h$ | P4 扰动 5 s、恢复绝对时刻、断联历时、窗口末端 60 s | p.5 |
| $k,N,η,t_{last}$ | 成功开测数、告警总数、完成率、官方计分的最晚开测时刻 | p.5 |

表内所有模型计算统一使用 m/s；明确角度函数输入是 ° 或 rad。官方仅 P3 指定误差；各问题先完成标称答案，再由队员批准扩展。阶段记录保留零时长动作，车辆导出 ID 统一显示 V1–V5，代码索引的 0–4 不可直接作为论文车号。五栋楼、初始点、三组告警及云台参数见 `../data/B题题面参数.csv`；转录主要数值已核对，未发现 B 题独立数据附件。

| 项 | 执行要求 |
|---|---|
| 1 原题 | p.4 “select two vehicles from the five available”及“travel time … does not exceed 30 s”。建与基线、交会角、距离相关的精度模型并解释指标与退化。 |
| 2 实际任务 | 双站观测方程、误差度量、逐车站域、站对选择、最优性和退化对策分别出证据。 |
| 3 输入 | T2=(150°,45 m,35 m)，五车起点与路线约束，独立 1° 标准差，30 s 行车时限，标称相机参数。 |
| 4 未知 | 两车 ID、两个 xy 站、基线、交会角、各自路线及行车时间、精度与证书。目标高由告警提供，状态估计为 xy。 |
| 5 约束 | 两车不同、站位可行、各自能在限制内真正到达、两条标称方位线具有独立几何信息。30 s 计行车，不计对准/观察时间。 |
| 6 目标 | 选经论证的定位精度最优。现稿是局部一阶水平位置 RMS，单位 m。可另报置信椭圆轴或误差分位数，单列各自统计意义。 |
| 7 理论 | 水平二维直线相交、方位观测雅可比、协方差/信息条件数、三角形基线与角关系。范围和角要检查是否能同时实现。 |
| 8 候选 | 一阶 RMS 简明并可尝试下界证书；条件数和椭圆对退化直观，指标排序可能不同；分位数/带拒绝的交会更稳健，但需书面决定拒绝策略和计算成本。 |
| 9 边界 | 近平行与反向、同点、几何边界、接近时限、角度绕回、噪声后的近平行。全支撑高斯下直接无截断求交在分母近零处重尾，有限样本 RMS 不证明总体二阶矩。 |
| 10 验证 | 复核 `B_P2_localization.csv` 的 V3/V5、两段路径、90° 和 0.143623 m。独立证明下界假设及同时取等，或限制“最优”范围。现有 ±1 mm 俯仰夹具可作为回归。 |
| 11 实验 | 等距正交 vs 非正交 vs 贴俯仰/遮挡边；一阶误差椭圆对照局部模拟分位与退化率；分别改角和距离，避免共变时错误归因。 |
| 12 图表 | T2 地图、两车辆路线与 30 s 约束、对照椭圆和退化角小图；图注注明一阶指标，二维 x/y 等比例。 |
| 13 依赖 | 通用可观测站与路线来自共享几何。可给 P2(2)/P4 提供几何诊断；强加精度阈值前需队员另列扩展。 |
| 14 风险 | 把 1° 当 1 rad；将水平距离写成斜距；将有限模拟 RMS 写成总体误差；把局部连续优化称为全局证明；把 p.4 的 30 s 移植到其他问。 |
| 15 人工决策 | 精度目标、交会角定义、退化应对、全局证书写法、是否单独展示鲁棒站对。 |

## 待队员签核的证据接口

| 证据包 | 验证夹具 | 通过条件 |
|---|---|---|
| 观测算子 | 对正东、正北和西方向站点以两种角度计算验证，逐观测扰动一个小量 | 单位为 rad 或有清楚的转换，局部方位偏导符号与数值差分一致 |
| 候选域 | 十个无序车对，全套初始车位；每对站点有自身可行性 | 对每车一条连续可行路径，先核路线长度和车速度，再核 ≤30 s。避免用直线距离排名代替可行路线 |
| 最优证据 | 当前同距正交站对，必要时同一目标构造非正交对照 | 证明的下界与选择的指标同一变量和单位；必要取等关系通过几何与道路可行性。若换指标，原证书须撤销并重查 |
| 退化对照 | 同站、重合方向、反向、很小的角度偏差；测线带不带方向约束分别定义 | 始终明确不可估计、拒绝或给出诊断；拒绝样本比例及样本集合固定 |
| 位置边界 | 站过俯仰圆与遮挡边界各两侧小量；时间阈值等于和略超 30 s | 区分角度线性条件与站点失效风险；审查在边界仍能达到主指标的条件 |
| 稳健性 | 同站对多 seed 抽样，依次试分位统计及显式的近共线拒绝规则 | 报种子、样本数和适用对象。保留一阶指标、截断或拒绝结果的命名，不混成一个 RMSE |

输入输出行建议包含 `vehicle_pair,station_pair,metric_id,noise_model_id,baseline_m,range_1_m,range_2_m,crossing_deg,route_1,route_2,travel_1_s,travel_2_s,feasible_reason`。名义站图若叠加误差椭圆，报告置信水平、特征轴与原点，防止将同尺度显示和放大插图混在一起。

队员负责选择理论指标、推导、求解及结果解释。两车方案先核各自治具，再比较成对几何。P2(2) 只读几何诊断，其时间目标和约束从正式题面单独建立。
