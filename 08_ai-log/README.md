# 08_ai-log — AI 工具使用台账

> 官方《数维杯人工智能工具使用规定（2026 修订）》**强制要求**。漏记可能被判违规。

## 用法

**每次用完 AI，立刻追加一行**到 `AI_USAGE_LOG.csv`。不要攒到赛末补 —— 补不全。

| 字段 | 说明 |
|---|---|
| `工具名称` | `WorkBuddy Agent` / `ChatGPT（Codex）` / … |
| `版本/型号` | `DeepSeek-V4.1-Flash` / `GPT-6` / … |
| `开发机构/公司` | `深度求索` / `OpenAI` / … |
| `使用日期` | `YYYY-MM-DD` |
| `使用环节` | 拆题 / 建模 / 求解 / 出图 / 写作 / 排版 / 自检 |
| `关键提示词` | 一句话概括让它干什么 |
| `输出要点` | 它产出了什么 |
| `采纳内容` | 实际用了哪些；没采纳写"未采纳" |
| `人工修改情况` | 队员改了哪里（**这一栏是自查 AIGC 比的依据**） |
| `对应章节或文件` | 追到具体路径 |
| `操作人` | 队员代号 |

## 赛末从这张表生成两样东西

1. **论文 References 里的 AI 工具条目**
   格式：`[编号] 工具名称，版本/型号，开发机构/公司，使用日期`
2. **《AI 工具使用情况报告》**（单独提交，**不占 25 页配额**）

## 别忘了

- 论文正文里要在**相应位置标注**哪些内容借助了 AI，并指向 References 的编号
- 代码里 AI 显著改写的部分要加注释标注
- 未使用任何 AI 工具的队员/环节，也要在论文里声明清楚
