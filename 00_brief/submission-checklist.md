## D. 结构完整性（官方评审原则覆盖）

- [ ] Abstract：问题 → 方法 → 模型 → **数字结果** → 结论，一页内
- [ ] Keywords 3–5 个，含核心模型名
- [ ] Problem Restatement：**改写**题面（不是复制，控相似比）
- [ ] Assumptions：每条附合理性说明
- [ ] Notations：表格化，符号全文一致
- [ ] Model Development：含「为什么选这个模型」的动机段
- [ ] Model Solution：算法步骤 + 参数设置 + 复杂度
- [ ] Model Validation：误差指标 + 基线对比 + 交叉验证
- [ ] Sensitivity Analysis：关键参数 ±10%/±20% 扰动，结论是否翻转
- [ ] Strengths & Limitations：具体、可检验
- [ ] Conclusions：回扣题目每一小问
- [ ] References ≥ 5 条，**按正文引用先后编号**、方括号 `[3]`、格式统一、全部真实可查
- [ ] 引用**书籍须标明页码**（如 `[2, pp. 45–47]`）；尽量用期刊/书籍，**不要用网址当主要来源**
- [ ] 参考文献格式：`[编号]作者，论文名，杂志名，卷期号:起止页码，出版年。`（书籍/网页格式见整理文档 §8）
- [ ] **附录 / 源码**：含实际使用的软件名称、关键命令（含 Excel/SPSS 交互操作命令）、**全部可运行源程序**；程序能跑且结果与正文一致
- [ ] 赛题提供的数据**不必**放附录；自主查阅的数据通常应放
- [ ] 若把附录移到 `…fj.zip`，**正文中已明确注明**（如 "All source codes are provided in the supporting materials."）
