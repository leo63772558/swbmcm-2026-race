## 四、四问速览（详细拆解见 `02_model/00-decomposition.md`）

| 问 | 要解决的事 | 关键难点 |
|---|---|---|
| **P1** | T1 的可观测区域 + 最优站位（质量指标 `Q = 1/r`） | 三重约束同时成立：车体几何 / 视线遮挡 / 云台俯仰角；"相切即遮挡"口径 |
| **P2(1)** | 双站交会定位精度模型 + T2 的最优站点对（行程 ≤ 30 s） | 精度指标怎么定义并自证合理；交会角趋近 0°/180° 与边界站的退化 |
| **P2(2)** | 三告警并发、五车六任务槽的车辆复用与路径；最小化最大观测开始时间 | 提出 `t_last`/`t_max` 型目标 + 与"最近分配启发式"基线对比 |
| **P3** | 定位误差与指向误差对水平方位精度的影响，求允许最大行程 | `σ(s)=a+bs` 双参数；`P(|Δψ|≤5°)≥0.95` 是**双侧尾概率**；近似方法要论证并验证 |
| **P4** | 扰动下的重调度：新告警 / 单车失效 / 通信中断及其组合 | `η` 优先、`t_last` 次之的字典序比较；已开始观测的任务不可重排 |

