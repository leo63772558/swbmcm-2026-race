## 0. 输入、符号和题设口径

| 符号或字段 | 含义与单位 | 来源 |
|---|---|---|
| $X,Y$；$O$ | 东、北坐标 m；调度中心 (50,50) m | p.1 |
| $F_j,H_j$ | 建筑平面闭矩形和高度 m | p.1 Table 1，CSV 五行对象 |
| $p_i,p_i^0$ | 车辆圆心 xy、初始 xy，摄像机高 2 m | pp.1、3 |
| $r_v,v$ | 圆盘 1.5 m、行车 3 m/s | p.2 |
| $θ,R,H$ | 告警正东逆时针方位 °、相对中心水平距离 m、目标高 m | pp.1–2 |
| $r,α,β$ | **站到目标**水平距 m、相机方位 °、相机俯仰 °；另以 $φ$ 表示从目标看站位的极角 | pp.1–3 |
| $D(p,q)$；$B,γ$ | 路线距离 m；站间基线 m、交会角 ° | pp.2–4 |
| $t_d,t_a,t_q,t_s,t_e,t_u$ | 出发、到站、对准就绪、联合开测、结束、复位完成的绝对时刻 s | p.3 |
| $s,σ(s),Δψ$ | 累计里程 m、单轴定位标准差 m、包角误差 ° | pp.4–5 |
| $t_0,t_{rec},d_{out},t_h$ | P4 扰动 5 s、恢复绝对时刻、断联历时、窗口末端 60 s | p.5 |
| $k,N,η,t_{last}$ | 成功开测数、告警总数、完成率、官方计分的最晚开测时刻 | p.5 |

表内所有模型计算统一使用 m/s；明确角度函数输入是 ° 或 rad。官方仅 P3 指定误差；各问题先完成标称答案，再由队员批准扩展。阶段记录保留零时长动作，车辆导出 ID 统一显示 V1–V5，代码索引的 0–4 不可直接作为论文车号。五栋楼、初始点、三组告警及云台参数见 `../data/B题题面参数.csv`；转录主要数值已核对，未发现 B 题独立数据附件。

| 2 实际任务 | 分成车体半径侵入、有限段三维接触、俯仰、区域绘制、主目标、平局与证据七项。 |

| 4 未知 | 可行中心集合、边界类型、最优集合、代表点、$r,β,Q$。如采用就绪规则再提供车辆、路径、到站和对准时刻。 |
| 5 约束 | 车体不能出界或进入建筑内部。有限视线段接触任何楼面、棱或点均失败。闭俯仰区间。分开点到矩形距离、线段到建筑距离及俯仰裕度。 |

| 7 理论 | 圆盘配置空间、点到矩形欧氏距、闭区间线段裁剪、透视阴影、水平极坐标与约束交集。 |
| 8 候选 | 公式判别＋层叠栅格，最低工程成本且区域面积为估计；解析/矢量阴影＋圆弧边界，证据可定位但需处理投影退化；用独立核对关键边和极值。 |
| 9 边界 | 车恰贴楼/场界、LOS 擦顶/顶点、$r=0$、俯仰恰为 80°、圆周跨 360°、多个平局点、阴影窄通道。 |
| 10 验证 | 从 [P1 复核](../P1_REVIEW.md) 跟进 R01–R12。两侧边界夹具、独立阴影交叉、原地重算代表点和到站路径。 |
| 11 实验 | 网格尺度和原点变化、独立抽样带 CI、俯仰/半径/高度分别变动。扫描每一行要有可行见证；换高度时按尺寸重新判断楼顶关系。 |
| 12 图表 | 极角域和最优弧局部放大，主图按三种限制拆图，图例区分闭可行边与排除阴影边。 |
| 13 依赖 | 复用通用谓词给 P2/P4；T1 单站主指标仅为本问。 |
| 14 风险 | 带近似的面积写成精确、错用弧长/角跨度、把保守路径当精确、把不同平局点当作数值矛盾。 |
| 15 人工决策 | 车端等号书面口径；平局规则；全弧证明或明确离散范围；拓扑是否给连续证明。 |

## 待队员签核的证据接口

| 用例 | 输入变化 | 期望核验 | 记录 |
|---|---|---|---|
| A1 场界 | 车辆中心从内侧到 1.5 m 边界与外侧 | 等号接触可行，出界失败 | 侧边、场角分别测，保存原始坐标 |
| A2 圆角 | 同一楼的缓冲矩形内、圆角域外 | 精确车体核可行，保守路径拒绝 | 标注距楼平面、场界距离，不与 LOS 合并 |
| A3 视线 | 面、棱、顶点擦边以及楼顶上方 | 接触判遮挡，远离棱柱的近邻点可看见 | 记录楼 ID、视线参数区间、浮点公差 |
| A4 最佳圆 | 精确计算圆和候选边界交点 | 比对报告端点、两侧分类、0° 接缝 | 带全精度坐标及区间角，不用四舍五入后点位断言 |
| A5 平局 | 当前样点 vs 260° 候选 | 主指标相同；选择依据与具体优先级一致 | 打印完整排序键、车位及路径源 |
| A6 面积 | 网格原点与步长变化，固定种子均匀样本 | 同样的单位和场地面积分母，区域边缘与误差一致 | 采样数、分辨率、CI、用的几何核 |
| A7 高度 | T1 标称、高度等于楼顶、低于楼顶 | slab 与投影分别处理，不能发散后静默删除 | 记录投影适用前提和源数据 |

P1 独立验收依次需要：注明接触约定的三层几何图 → 全局质量可行见证 → 圆弧边界清单 → 单一代表与可重复平局。若报告连通性和敏感性，分别追加独立证据；候选文档的原始面积与 215 顶点图日志需先找原作者。

导出建议字段为 `constraint_id,position_x_m,position_y_m,pitch_deg,los_building,body_clearance_m,status,epsilon_policy`。面积比较另建 `method,mesh_m,offset_xy,count_or_samples,seed,area_m2,interval_lo,interval_hi`。图对于未拿到完整证书的图层使用“sampled region”或“boundary estimate”等真实标签。
