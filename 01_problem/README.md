## 题面里的关键口径（建模前必须先对齐，别自己重定义）

1. **目标高度 H 是告警直接给的，不由交会解算**。H 只用于三件事：判断视线仰角是否在云台范围内、判断是否被建筑遮挡、P3 的指向误差分析。
2. **遮挡判定"相切即遮挡"**：视线段与任一建筑棱、面、顶点相切或接触，都算遮挡。
3. **观测站可观测需三条同时成立**：车体几何（场内 + 不侵入建筑）、视线无遮挡、云台俯仰角 ∈ [−10°, 80°]。
4. **行程中云台保持正东水平姿态**，车停稳后才转向目标；重置也是先回到正东水平姿态，再出发。
5. **P2(1) 的 30 s 是"从初始位置到观测站的行程时间"上限**，不是总任务时间。
6. **P4 的 η 优先、t_last 次之**：先比完成率，η 相同才比最晚观测开始时间。
