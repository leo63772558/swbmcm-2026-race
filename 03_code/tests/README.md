# tests — 单元测试

```bash
python -m pytest 03_code/tests -q
```

## 必须有测试的部分

几何与遮挡判定是本题的地基，错了整篇论文都错。至少覆盖：

| 用例 | 期望 |
|---|---|
| 点在建筑内部 | `disk_clear_of_buildings` → False |
| 点距建筑边 1.4 m（圆盘半径 1.5） | → False（侵入） |
| 点距建筑边 1.6 m | → True |
| 视线穿过建筑内部 | `segment_blocked` → True |
| 视线**恰好擦**建筑棱 | → True（相切即遮挡） |
| 视线恰好擦顶点 | → True |
| 视线完全避开 | → False |
| 仰角 80.1° / −10.1° | 不可观测 |
| 仰角 79.9° | 可观测 |
| 目标坐标换算：θ=0°, R=10 | (60, 50) |
| 目标坐标换算：θ=90°, R=10 | (50, 60) |

## 命名

`test_<被测算子>.py::test_<情形>`，失败时输出里能直接看出哪条口径挂了。
