# P3 代码

**负责人**：Member B（电气）　**建模文档**：`02_model/P3.md`　**入口**：`run.py`

| 项 | 内容 |
|---|---|
| 输入 | 各误差源标准差、目标水平距离 40 m |
| 输出 | `04_results/p3_max_distance.csv`、`p3_ab_feasible.csv`、`p3_error_contrib.csv`、两张图 |
| 怎么跑 | `python 03_code/run_all.py --only P3` |

## 要做的事

1. 建 `Δψ` 的误差传播模型（三个独立误差源）
2. 解 `P(|Δψ| ≤ 5°) ≥ 0.95` 得最大允许累计行程 `s`
3. 行程 80 m 时，反解 `σ(s) = a + b·s` 中非负 a、b 的约束（是**可行域**，不是一个数）
4. 论证近似方法（线性化 vs 蒙特卡洛交叉验证）
5. 三误差源相对贡献对比

## 注意

- **双侧**尾概率（陷阱 #4），按单侧算会大错
- `s` 是**累计行驶距离**，多段行程要累加
- 蒙特卡洛要写 seed，样本量要说明收敛性
