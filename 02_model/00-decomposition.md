## 全局已知（题面直接给出，不用讨论）

场地 100 m × 100 m 正方形，原点在西南角，x 向东、y 向北；调度中心 O = (50, 50)。
5 个轴对齐长方体建筑 B1–B5（平面范围与高度见 `01_problem/data/buildings.csv`）。

相机高 2 m，云台俯仰可行范围 [−10°, 80°]，两轴最大角速度 30°/s，两轴可同时转，**转向耗时取两轴中较长的那个**。

## P3 · 定位与指向误差对水平方位精度的影响

**题面事实**

| 项 | 内容 |
|---|---|
| 误差源（三者独立） | ① 车体定位误差：行驶累计距离 s 后，水平坐标误差独立零均值正态，`σ(s) = 0.3 + 0.02·s`（m）；② 云台零位误差 `σ = 0.8°`；③ 云台控制误差 `σ = 0.6°` |
| 机制 | 云台用**估计位置**算指向角，因此定位误差会通过几何关系传进方位偏差 `Δψ`（定义：指令方位角与真实方位角之差，卷绕到 [−180°, 180°)） |
| 固定条件 | 目标位置视为精确已知；车到目标的**水平距离固定 40 m** |
| 要交 | `Δψ` 的误差传播模型 + 满足 `P(|Δψ| ≤ 5°) ≥ 0.95` 的最大允许累计行驶距离 + 若行程 80 m 仍要满足该要求，反解 `σ(s) = a + b·s` 中非负参数 a、b 的约束 + 近似/数值方法的适用性论证与验证 + 三个误差源的相对贡献对比 + 部署建议 |

## P4 · 扰动下的重调度与方案对比

**题面事实**

| 项 | 内容 |
|---|---|
| 基线 | P2(2) 的调度方案 |
| 扰动（t = 5 s 发生，可单独可组合） | ① 新告警：需 2 车，参数 θ ∈ [0°,360°)、R ∈ [30,50] m、H = 50 m；② 五车中恰有一辆随机失效（等概率），失效车退出服务且不阻挡通行；③ 通信中断区间 [5, t_rec]，`t_rec ∈ (5, 30]`，中断期间车继续执行原任务，恢复后才收到新指令 |
| 不可重排 | 扰动前**已开始观测**的告警视为完成，不得重排；已派出但尚未开始观测的车可改派 |
| 信息结构 | 两个方案在 t=0 排程时都**不知道**扰动；重调度只能用实时信息、且扰动真实发生后才触发 |
| 评价 | 窗口 t ∈ [0, 60] s；N = 窗口内应观测告警总数（含新增），k = 成功开始观测的告警数（**两车都到位并完成指向才算成功**）；`η = k/N`；`t_last` = 最晚观测开始时间，窗口内无法开始则记 60 s |
| 排序 | **先比 η 大，η 相同再比 t_last 小**（字典序） |
| 要交 | 重调度模型 + 与"保留原方案"策略的对比 + 单扰动与组合扰动的结果 + 新告警参数 (θ,R,H) 的不确定性下的场景集设计及理由 + 各场景的 (η, t_last)、重调度策略、车辆时间轴 + 什么情况下重调度有收益、什么情况下反而更差及其原因 |

## 全局概念陷阱清单（建模前先读一遍，别踩）

| # | 陷阱 | 后果 |
|---|---|---|
| 1 | **交会角趋近 0° 或 180° 时两方位线近乎平行/反向平行**，交点对误差的放大趋于无穷 | P2(1) 若不加约束，最优解会跑到退化区 |
| 2 | **P1 的"相切即遮挡"**：几何库默认"相切算不相交"，直接用会得到偏乐观的可观测区域 | 可观测区域边界画错，整问连锁错 |
| 3 | **车体是有半径的圆盘**，站点不是"点在场内"，而是"圆盘完全在场内且不碰建筑" | 边界附近的站点被误判为可行 |
| 4 | **P3 是双侧尾概率** `P(|Δψ| ≤ 5°)`，不是单侧；按单侧算会把允许行程算大 | 结论直接错一个量级 |
| 5 | **`σ(s) = a + b·s` 的 s 是累计行驶距离**，不是位移；多段行程要累加 | P3 第二问的约束写错 |
| 6 | **P4 是字典序**（先 η 后 t_last），不是加权和 | 加权和会选出"完成率低但 t_last 小"的荒谬方案 |
| 7 | **P4 评价窗口内无法开始观测的告警，t_last 记 60 s**（不是无穷大、也不是不计） | 目标值算错 |
| 8 | **P2(1) 的 30 s 是行程时间上限**，不含云台转向和 5 s 观测 | 可行域被放大 |
| 9 | **云台转向耗时取两轴较大值**（同时转），不是两轴相加 | 时间轴整体偏长，P2(2)/P4 全错 |
| 10 | 题面的 θ 是**自正东逆时针**，与常见的"自北顺时针"方位角相反 | 目标坐标算反，全盘皆错 |
