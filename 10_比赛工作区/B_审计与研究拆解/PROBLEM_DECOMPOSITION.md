# B 题问题树与分工手册

适用依据为 [官方赛题发布](https://www.nmmcm.org.cn/Awards/228.html) 所附五页英文 B 题，页码为 PDF 物理页。现有结果和脚本用来寻找证据与漏洞。本文是研究任务书。队员需提交自己的推导、选择记录、运行结果和解释。

## 0. 输入、符号和题设口径

| 符号或字段 | 含义与单位 | 来源 |
|---|---|---|
| $X,Y$；$O$ | 东、北坐标 m；调度中心 (50,50) m | p.1 |
| $F_j,H_j$ | 建筑平面闭矩形和高度 m | p.1 Table 1，CSV 五行对象 |
| $p_i,p_i^0$ | 车辆圆心 xy、初始 xy，摄像机高 2 m | pp.1、3 |
| $r_v,v$ | 圆盘 1.5 m、行车 3 m/s | p.2 |
| $θ,R,H$ | 告警正东逆时针方位 °、相对中心水平距离 m、目标高 m | pp.1–2 |
| $r,α,β$ | **站到目标**水平距 m、相机方位 °、相机俯仰 °；另以 $φ$ 表示从目标看站位的极角 | pp.1–3 |
| $D(p,q)$；$B,γ$ | 路线距离 m；站间基线 m、交会角 ° | pp.2–4 |
| $t_d,t_a,t_q,t_s,t_e,t_u$ | 出发、到站、对准就绪、联合开测、结束、复位完成的绝对时刻 s | p.3 |
| $s,σ(s),Δψ$ | 累计里程 m、单轴定位标准差 m、包角误差 ° | pp.4–5 |
| $t_0,t_{rec},d_{out},t_h$ | P4 扰动 5 s、恢复绝对时刻、断联历时、窗口末端 60 s | p.5 |
| $k,N,η,t_{last}$ | 成功开测数、告警总数、完成率、官方计分的最晚开测时刻 | p.5 |

表内所有模型计算统一使用 m/s；明确角度函数输入是 ° 或 rad。官方仅 P3 指定误差；各问题先完成标称答案，再由队员批准扩展。阶段记录保留零时长动作，车辆导出 ID 统一显示 V1–V5，代码索引的 0–4 不可直接作为论文车号。五栋楼、初始点、三组告警及云台参数见 `../data/B题题面参数.csv`；转录主要数值已核对，未发现 B 题独立数据附件。

## 5. P4｜扰动、保留方案和重调度

| 项 | 执行要求 |
|---|---|
| 1 原题 | p.5 “baseline”指 P2(2)；“ongoing tasks”及“before the disturbance”涉及状态语义。报告单扰动、组合、逐情景 $(η,t_{last})$、策略和车辆时间线，解释得失。 |
| 2 实际任务 | 冻结名义计划、事件时钟、状态重建、受损任务锁定/撤销、候选改派、同情景保留政策、计分和机理复核。 |
| 3 输入 | t=5 新警报和/或等概率一车故障和/或断联；新警报 $θ∈[0,360)$、$R∈[30,50]$ m、$H=50$ m；窗口 [0,60] s。规划 t=0 时无预知。 |
| 4 未知 | 每车实时位置、云台阶段及姿态、可用时刻，已执行与未开测告警，取消指令和回零，逐任务新分配，逐情景成绩。 |
| 5 约束 | 故障车退出且不挡路；扰动前已开测锁定；已派未开测可改派；断联期间无新指令；恢复后由可用状态推出新动作；任一策略按共同体积、LOS、俯仰、车对、阶段规则。 |
| 6 目标 | 先最大 $k/N$，同完成率再最小 $t_{last}$；存在没按期开始的任务时 $t_{last}=60$。恢复用时另定义起止事件。 |
| 7 理论 | 离散事件、资源占用、动态路由、配对情景比较、可靠性覆盖，不假定传感物理场或故障强度模型。 |
| 8 候选 | 事件触发有限枚举/束搜索可复用验证；冻结既执行前缀＋局部修复成本低，但应检验卡死情景；比较“当下任务继续”与“完整计划缓存”两种执行口径。 |
| 9 边界 | 扰动恰开测（题面严格 before），恢复恰开测的先后，59.999/60/60.001 s；车在到站/在途/对准/等待/开测/复位的状态；故障搭档能否感知，回零计时及断联前已发但未开的后续任务。 |
| 10 验证 | 复算每对政策的 $k,N,t_{last}$；恢复用路线弧长插值，不直连起终点；用同一车-告警双端检查同步；逐状态测试未开测误保留及失败车被重新分配。 |
| 11 实验 | 七种非空扰动族均有覆盖。已有 28 对及三位置×五故障车×三个时刻 45 对补充；后者与原表重合 11 对。其余按边界/遮挡/资源竞争分层，新增位置与恢复时刻不默认有概率分布。 |
| 12 图表 | 严格区分完成率与截尾时间；分面情景矩阵，配恢复时钟和典型逐车甘特。至少给一个有效、一个持平或变差的案例，不用示意动画替代时间线。 |
| 13 依赖 | P2(2) 名义计划＋共享几何。P3 航程风险只能做另列研究；官方评分仍使用标称几何和时钟。 |
| 14 风险 | 混淆故障时、恢复时、历时；未来缓存与新调度混淆；比较基线偷看事件；60 s 截尾当速度提升；局部场景统计冒充场景总体期望。 |
| 15 人工决策 | 主恢复区间；仅正在执行或完整缓存；同步任务故障后搭档是否保持对准；恢复同刻事件优先级；保留原方案是否亦可成为重调度的备选行动。 |

### P4 时钟裁决表

| 项 | 题面或核验规则 | 要记录的字段 |
|---|---|---|
| 扰动 | p.5 固定 5 s。故障、新告警和断联可同刻发生 | `disturbance_s` 和各事件开关 |
| 公式口径 | $t_{rec}∈(5,30]$ 为绝对恢复时刻，因此对应历时 (0,25] s | `recovery_s`、`duration_s`、`time_interpretation` |
| 文字口径 | 历时 [5,30] s，对应绝对恢复 [10,35] s | 30 s 绝对和 30 s 历时必须独立列名。35 s 只能进文字口径 |
| 仅新警报/故障 | 不断联时可以在 5 s 触发；把通信状态和恢复使用字段分开 | `has_outage=false`、`trigger_s=5` |
| 窗口 | 题意含“before the end”，候选的计分用严格小于 60 s | `horizon_s`、`cutoff_rule`、`official_latest_s`、`actual_last_started_s` |
| 制约 | 扰动前已开测按完成计；5 s 精确同刻不能使用“先于 5 s”豁免 | `locked_alerts`、`failed_pairs`、原/新事件顺序 |
