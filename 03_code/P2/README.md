# P2 代码（两个子任务）

| 子任务 | 负责人 | 入口 | 建模文档 |
|---|---|---|---|
| P2(1) 双站精度模型 + T2 最优站点对 | Member C（生信） | `run_p2_1.py` | `02_model/P2-1.md` |
| P2(2) 三告警并发的车辆复用与路径 | Member A（软工） | `run_p2_2.py` | `02_model/P2-2.md` |

## P2(1)

| 项 | 内容 |
|---|---|
| 输入 | 目标 T2、五车初始位置、T2 的可观测区域（P1 的产物） |
| 输出 | `04_results/p2_1_station_pair.csv`、精度-交会角关系图 |
| 硬约束 | 每车行程时间 ≤ 30 s |

要做的事：精度模型 → 定义指标并论证 → 枚举/优化选最优站点对 → 讨论退化。

## P2(2)

| 项 | 内容 |
|---|---|
| 输入 | 三告警的可观测区域、五车初始位置、时序规则参数 |
| 输出 | `04_results/p2_2_schedule.csv`、`p2_2_timeline.csv`、`p2_2_heuristic_compare.csv`、甘特图 |
| 目标 | **最小化三个告警中最大的观测开始时间** |

要做的事：min-max 排程 → 输出每车完整时间轴 → 自定义"最近分配启发式"求基线 → 对比并分析差异来源。

## 注意

- 云台转向耗时 = 两轴中**较长**的那个，不是相加
- 观测 5 s，复位也要算时间
- 30 s 只约束 P2(1) 的行程，不含转向与观测
