## 要做的事

1. 三类扰动（新告警 / 单车失效 / 通信中断）及组合的建模
2. 重调度模型 + 与"保留原方案"逐场景对比
3. 新告警 `(θ,R,H)` 不确定性下的**场景集设计**及理由
4. 各场景的 `(η, t_last)`、重调度策略、车辆时间轴
5. 分析**什么情况下重调度有收益、什么情况下反而更差及原因**（这问明确要求）

## 注意

- 排序是**字典序**：先 η 大，η 相同再 t_last 小（不是加权和）
- 窗口内无法开始观测 → `t_last = 60 s`
- 已开始观测的告警不可重排；已派出未开始观测的可改派
- t=0 排程时两个方案都不知道扰动
