# 03_code — 代码

> AI 的主战场。**一行命令必须能跑出全部结果与图**。

## 入口

```bash
python 03_code/run_all.py          # 跑全部（P1→P2→P3→P4）
python 03_code/run_all.py --only P2 # 只跑某一问
```

## 每个模块的 README 要写四件事

**输入 → 输出 → 怎么跑 → 依赖哪个 CSV**。缺一条就算没写完。

## 硬性代码约定

| 约定 | 原因 |
|---|---|
| 随机过程**固定 seed**，seed 写进 `04_results/notes.md` | 否则图与正文数字不可复现 |
| 结果一律写 `04_results/*.csv`，**不 print 就算了事** | 正文数字必须能追到 CSV |
| 图同时导 **PDF + PNG**，脚本存 `03_code/` | 只丢图不丢脚本 = 不可复现 |
| 角度换算处显式标 `deg` / `rad` | 度弧度混用是本题最容易出错的地方 |
| 函数参数名与 `02-notation.md` 符号表一致 | 审代码时能直接对上公式 |
| 关键不变量加 `assert` | 站点在场内、不侵入建筑、交会角 ∈ (0°,180°)、时间轴单调 |
| **不得出现姓名 / 学校** | 匿名评审，代码注释里也不行 |
| AI 显著改写的函数在文件头注明 | 官方 AI 申报要求 |

## B 题工程复核交接

赛时复核的版本化实现位于 `10_比赛工作区/src/`。输入为 `data/B题题面参数.csv`、存档 `results/B_*.csv` 及复核包的 CSV/JSON。入口为 `python -B 10_比赛工作区/src/reproduce_b_revision.py --out <新目录>`，输出为对照结果、8 组 Matplotlib 图、3 组帧、3D 离线回放和复跑清单。PDF 构建与浏览器检查见复核包的 `REPRODUCE.md`、`VERIFY_REPORT.md`。
