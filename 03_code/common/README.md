# common — 公共几何（四问共用）

> ⚠️ **改动这里会影响全部四问。改之前先在群里说一声。**

## 应该在这里实现的东西

| 函数 | 作用 | 注意 |
|---|---|---|
| `target_xy(theta_deg, R)` | 由告警算目标水平坐标 | `(50 + R·cosθ, 50 + R·sinθ)`，θ **自正东逆时针** |
| `elevation_angle(p_cam, p_target)` | 视线仰角 | 相机高 2 m，须落在 [−10°, 80°] |
| `disk_inside_field(x, y, r=1.5)` | 车体圆盘是否完全在场内 | **不是判断点在场内** |
| `disk_clear_of_buildings(x, y, r=1.5)` | 圆盘是否不侵入建筑 | 贴边（距离恰 = 1.5）按可行还是不可行，**由队员拍板后写进假设 A2** |
| `segment_blocked(p1, p2, buildings)` | 视线是否被建筑遮挡 | **相切 / 接触即算遮挡**，这是题面明写的口径 |
| `slew_time(from_deg, to_deg, rate=30)` | 云台转向耗时 | 两轴取**较大值**，不是相加 |

## 惯例

- 角度参数一律带 `_deg` 后缀，内部计算可转弧度但转换处要显式写
- 距离单位统一米
- 每个函数配一个测试在 `03_code/tests/`
- 遮挡判定是本题最容易出错的函数，**必须测边界情形**：视线穿建筑内部 / 只擦棱 / 只擦顶点 / 完全避开
